# OCT 弱边界图像分割项目（Asthma OCT Image Segmentation）

🎯 本项目致力于实现肺部相关病灶的光学相干断层扫描（OCT）图像自动分割，包括对上皮、水肿、黏液和皱襞等复杂结构的识别与提取。项目由我与广州呼吸健康研究院合作，已获得国家级大创项目立项支持。

---

## 📌 项目背景

OCT 图像在呼吸道疾病早期筛查中有着广泛应用，但图像常呈现灰度不均、边界模糊等特性，常规分割方法难以适应。我们针对这些挑战，探索了多种基于灰度、图论及深度学习的图像分割方法。

---

## 🧪 方法概览

### 1. 图像预处理与增强
- 极坐标变换与霍夫直线检测（用于ROI标准化）
- 中值滤波、双边滤波、高斯滤波（噪声抑制）
- CLAHE 对比度增强（提升病灶可分性）

### 2. 分割算法尝试
- 基于灰度值：自适应阈值、Otsu、multi-Otsu
- 图论方法：随机游走算法、动态图划分
- 形态学方法：闭运算、边缘修复
- 深度模型尝试：U-Net / R-CNN（实验性模块）
- 分水岭算法：优化边缘重叠区域分离
